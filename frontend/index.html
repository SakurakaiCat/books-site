③ 使用帮助 — 下载之后怎么打开？

两件小事：用什么软件看 PDF、ZIP 压缩包怎么解压。

📖 用什么软件打开 PDF？

  • Windows / Mac 电脑

    首推 Adobe Acrobat Reader（免费，官网 adobe.com 下载）；或者什么都不装——把 PDF 文件直接拖进 Chrome / Edge 浏览器窗口就能看。

  • iPhone / iPad

    系统自带的「图书」App 点开就能读；也可以装免费的 Adobe Acrobat Reader App。

  • 安卓手机

    用自带的「文件管理」打开，或装 Adobe Acrobat Reader、WPS Office（应用商店搜索即可，都免费）。

📦 ZIP 压缩包怎么解压？

  • 苹果（iPhone / Mac）

    不用装任何软件：在「文件 / 访达」里点一下（或双击）ZIP，它就自动变成普通文件夹。

  • 安卓手机

    用自带的「文件管理」点开 ZIP；打不开就装免费的 ZArchiver（应用商店搜 ZArchiver），点 ZIP → 解压。

  • Windows 电脑

    推荐免费的 7-Zip（7-zip.org）或经典的 WinRAR：装好后右键点 ZIP → 「解压到当前文件夹」。

🔑 关于密码：本站所有 PDF 打开阅读不需要任何密码。如果某个阅读器打开时非要你输入密码，不要慌——那只是这个软件不兼容，换一个 PDF 阅读器（首推 Adobe Acrobat Reader）就能正常阅读。
